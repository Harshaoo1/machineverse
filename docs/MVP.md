# MachineVerse MVP

**Pitch:** Understand. Explore. Experiment. An interactive platform that teaches how machines work, starting with one vehicle.

## MVP rule

One machine, one good 3D experience, one knowledge system, one basic diagnostic system, one basic experiment system.

## First vehicle

A generic naturally aspirated gasoline inline-4 car, focused on the engine. Specific cars (such as the Toyota Supra) come later as additional vehicles.

## In scope (Phases 0-8, static front-end only)

- Home page and one vehicle page
- 3D engine with about 12 clickable components
- Info panel with Beginner / Intermediate / Advanced levels
- One short beginner learning path
- One diagnostic flow: "Engine won't start"
- One experiment: "Add a turbo", with a few controls and clearly labelled assumptions

## Out of scope for now

Backend, accounts, database, AI, other vehicles, exploded view, cost modelling.

## User flows

1. **Explore:** Home, then Car, then Engine, then click a component and read its explanation at the chosen level.
2. **Diagnose:** "Engine won't start", answer simple questions, see possible causes with the related components highlighted, then safe checks and when to call a professional.
3. **Experiment:** Add a turbo, set boost and intercooler, press Simulate, then see the estimated changes and why they happen.
